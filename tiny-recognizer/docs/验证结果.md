# 本次实际验证

日期：2026-10-16（用户时区 Asia/Shanghai）。本次环境为 Linux、Python 3.12、PyTorch 2.5.1+cpu、torchvision 0.20.1+cpu；使用 2 个 PyTorch CPU 线程。**没有 RTX 4090，也没有运行 Qwen3-VL 教师服务。**

## 已验证

| 验证 | 实际结果 |
|---|---|
| 官方公开权重 | D-FINE Nano 与 TinyCLIP 下载完成并通过 SHA256 校验 |
| 真实图片开放词汇基线 | dog.jpg 输入 5 个自定义类别，包括 `samoyed dog`；输出 1 个 `samoyed dog` 框；这是单样例展示，不是精度评测 |
| Nano 训练 | 合成图形数据、128×128、batch=2、2 步更新，前向/损失/反向/优化/保存成功；总损失 25.7955 → 23.2921 |
| Micro 训练 | 同样合成数据，1 步更新成功，损失 17.2284；仅用于证明更小架构可训练 |
| 新词表推理 | 训练词表为 3 个图形；加载 checkpoint 后改为 5 个完全不同的查询名称，前向和输出保存成功；默认阈值下无检测，不宣称零样本准确率 |
| 动态类别维度 | 2 类切换成 137 类，输出分类维度改变，可训练参数个数保持不变 |
| 评测流程 | 对独立合成验证图执行 F1 和 COCO AP，base/novel 分组正常；样例内容哈希检查通过 |
| 自动测试 | 坐标、动态词表、匹配、教师失败/缓存、AP、数据重叠共 7 项测试通过，耗时约 2.90 秒；依赖检查通过 |

真实图片基线得到的框为原图像素 `[155.24,34.32,1461.09,1149.82]`，标签 `samoyed dog`，启发式分数约 0.389，未经校准。整个区域与图中文字名匹配来自真实预训练权重；不是 Qwen 标注，也不是硬编码输出。

基线这一次 CPU 图像路径约 2.53 秒（640×640、24 个候选上限、包含密集窗口，无预热）。Nano smoke checkpoint 在 128×128、已有文本原型的条件下单次 CPU 图像路径约 15ms。两个数字对应完全不同的路径和分辨率，仅用于记录本次运行；**不能用它们比较准确率、推算 4090 FPS，或作为稳定的延迟基准。**

两步训练后，合成验证集在 F1 阈值 0.25 下 F1=0，AP50:95 约 0.00224（0–1 标度）。这些数值说明模型远未训练完成，保存它们是为了证明评测管线执行过，并避免把 smoke test 误认为可用精度。
